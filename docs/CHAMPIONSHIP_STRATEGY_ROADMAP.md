## 二、未來幾天三大主要行動方針 (Three Major Strategic Pillars)

```
       【柱石一：自動化情資爬蟲】         【柱石二：實戰復盤反饋迴路】         【柱石三：戰情中心與報告終審】
     (隊友/爬蟲腳本分工負責)             (AI Agent 自動化對帳演化)           (競賽答辯與可解釋性殺手鐧)
   - MOPS 觀測站法說/營收重訊           - 每日開盤比對「預測 vs 實戰」       - 一鍵產出期末 Active Share 報告
   - 鉅亨網/經濟日報高密度重點           - 萃取賺賠經驗為「新時空錨點」       - 雙向因果圖譜與會審逐字稿展示
   - 自動寫入 inputs/raw_reports/       - 空方自動引用前案防止追高踩雷       - 證明系統具備真正「量化避險靈魂」
```

---

### 方針 1：情報庫與爬蟲擴充（隊友與爬蟲分工）
* **核心任務**：打造輕量爬蟲或蒐集腳本，把情報源源不絕餵進 `inputs/raw_reports/*.txt`。
* **蒐集重點**：
  1. **公開資訊觀測站 (MOPS)**：台股 150 檔成分股的最新「法說會簡報摘要」、「月營收 YoY% 公告」。
  2. **專業財經新聞（鉅亨網 / 經濟日報）**：聚焦「CoWoS/先進封裝擴產」、「GB200 水冷伺服器」、「高階 CCL 供需」、「ASIC/載板拉貨」。
* **系統處理流程**：
  * 隊友把純文字存入 `inputs/raw_reports/` 後，直接執行：
    ```bash
    python scripts/ingest_intelligence.py
    ```
  * 系統自動：① Python 關鍵字過濾 80% 雜訊 ➔ ② LLM 提煉標準三段式因果 ➔ ③ 自動縫合進 `dossier_ledger.json` 並點亮戰情圖譜！

---

### 方針 2：打造「自主復盤反饋檢討迴路 (Post-Mortem Loop)」
* **核心任務**：在 `scripts/post_mortem_review.py` 實作自動問責機制。
* **工作機制**：
  1. **比對盈虧**：每日盤後比對「多空會審裁決」與「次日開盤撮合漲跌」。
  2. **成效問責**：
     * **成功案例（如穩懋漲停、廣達避震）**：強化該因果鏈信心度。
     * **失敗案例（如世界破底、景碩回檔）**：將虧損原因自動提煉為一筆新的 **`HistoricalAnchor`（歷史時空錨點）**。
  3. **次日引用**：在後續的多空會審中，空方風控師會自動搬出這筆錨點（例如：*「你忘了上次景碩追高被套嗎？鈍化期已到！」*），實現真正自我進化的避險行為。

---

### 方針 3：精簡與穿透（斷捨離保證高速度與高穩定）
* **核心任務**：利用剛建好的「LangGraph 思考軌跡穿透檢視」，評估各節點耗時。
* **策略規則**：
  * 核心 24 檔持股維持深度多空對審。
  * 一般非核心持股走快速規則通道，避免 Token 浪費與超時。
  * 確保每日 8:30 前在 3 分鐘內極速產出 100% 合規之 D-Plan。
